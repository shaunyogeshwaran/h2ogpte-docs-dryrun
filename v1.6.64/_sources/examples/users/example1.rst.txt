List all registered users in the system
=======================================

Overview 
--------

A user can retrieve a list of all registered users in the system. The system defines a registered user as one who is logged in at least once.

Example 
-------

.. code-block:: python

    from h2ogpte import H2OGPTE

    client = H2OGPTE(
        address="https://h2ogpte.genai.h2o.ai",
        api_key='sk-XXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX',
    )

    users = client.list_users(offset=0,limit=10)

    for user in users: 
        print(
            f"Model computed fields: {user.model_computed_fields}\n"
            f"Model config: {user.model_config}\n"
            f"Model fields: {user.model_fields}\n"
            f"Username: {user.username}"
        )
