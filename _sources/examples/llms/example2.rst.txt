List available LLMs 
===================

Overview 
--------

Users can access a list of available large language models (LLMs) within the environment. 

Example 
-------


.. code-block:: python

    from h2ogpte import H2OGPTE

    client = H2OGPTE(
        address="https://h2ogpte.genai.h2o.ai",
        api_key='sk-XXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX',
    )

    for item in client.get_llm_names():
        print(item)
